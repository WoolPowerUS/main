# Woolpower US Shopify theme

Theme for the Woolpower US Shopify store, connected through Shopify's GitHub integration.

- Base: Shopify Horizon 4.4.0
- `config/settings_data.json`, `templates/*.json`, `sections/*-group.json` and `AGENTS.md` are copied from the store's live Horizon theme as of 2026-11-10.

Changes made in the Shopify theme editor are committed back to this branch by Shopify. Changes pushed here are synced to the connected theme.
